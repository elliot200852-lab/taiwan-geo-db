## 動手前必讀
1. `docs/CONTENT-SPEC.md` —— 權威規範。

3. 你的派工單指定的**市級母本**（新北批＝`content/new-taipei/new-taipei.md`；
   臺北批＝`content/taipei/taipei.md`）——你的內容不可與它重複展開。
4. 你的派工單指定的「鄰區母本」——避免與它重疊。

## A. 篇幅與比例（最重要，第一批最大的問題）
- 正文 **4,500–5,200 字**（不含 frontmatter）。第一批平均比宜蘭基準線長 38%，太長。
- **`## 教學特點` 必須佔全文 35% 以上**（規格底線是 1/3，這裡多給緩衝）。
- **達成方式是控制〈人文地理〉的長度，不是灌水教學特點。** 第一批有 4 篇因為人文地理
  膨脹而讓教學特點佔比掉到 1/3 以下，其中兩篇是硬違規。
- **`## 定位速覽` 嚴格 ≤150 字**，超一個字都算沒過。

## B. 文風（David 的硬規則，第一批被抓出 15 條違規）
- 禁對立翻轉句式。實際被抓到的長相：「這不是 X，是 Y」「不是…而是」「與其說…不如說」
  「不僅是…更是」「A 從來不是…，是…」。**一句都不准出現。**
- **禁「每段收一句金句」的節奏。** 第一批有一篇每千字 3.3 句段末格言，讀起來很疲勞。
  段落該結束就結束，不必每段都拉一句對仗的收束。
- 禁機械對仗排比（「船停在哪裡，街就長在哪裡」這種）與破折號金句。
- 禁地方誌流水帳（歷任首長、機關學校列表、節慶羅列）。**特別是行政沿革**
  （改鎮→升格→改制那種年份串）——第一批兩篇就是被這種段落吃掉篇幅的，最多壓成一句。
- 段落敘事體、教師可直接讀。正文兩節不准用 bullet（教學特點那節可以）。
- 讀者＝教師（備課用），文字尺度 5–9 年級通識，不幼稚也不學術化。

## C. 數字格式
**年份、人口、面積一律用阿拉伯數字**（「1960 年代」「386,157 人」），不要用國字。
第一批有一篇全篇國字，八頁連著讀一眼就看得出不是同一批寫的。

## F. 事實紀律
- **禁止幻覺**。`sources:` 逐條列**實際查證過**的 URL；查不到就寫「待查證」，不硬掰。
- 人口／面積引官方：新北批＝新北市民政局人口統計
  <https://www.ca.ntpc.gov.tw/home.jsp?id=88f142fb0f4a0762>
  （可用 POST 帶 `yyyy=115&mm=5` 取 2026-05 的表）；臺北批＝臺北市民政局
  戶籍人口統計（ca.gov.taipei，自行找到最新月份的區級表）；基隆批＝基隆市民政處
  戶籍人口統計（klcg.gov.tw，自行找到最新月份的區級表；縣頁 stats 用的是
  2025-12 基隆市民政處，你拿得到更新的就用更新的並標年月）。一律標明資料年月；
  官方表拿不到就用維基彙整並如實標註來源層級。
- 可用 WebSearch / WebFetch 查證。
- **外部站活性紀律**：要對同一個網域密集查證之前，先 `curl -sI -m 10 <該站任一頁>`
  探一次活性；探不到或逾時就把該網域列入本次拒訪清單，相關條目標
  「無法覆核（來源站當機）」——這是合格結論，不是缺陷。任何外部請求超過 15 秒
  沒回應就放棄該條改標「待查證」，同一網域連續失敗兩次後不准再打。
- **「最」「唯一」「第一」這種絕對宣稱一定要查到權威來源才寫**，查不到就改保守表述。
  第一批就有兩處派工單寫錯（說烏來人口最少、說某工程保護某區），是 agent 自己查出來更正的——
  **派工單寫的東西也可能是錯的，以你查到的官方資料為準，並在回報裡告訴我。**

## G. 圖片紀律（對外公開站，授權標錯比事實錯更難善後）
- **Wikimedia Commons**：授權與作者一定要打 API 讀出來，不准憑印象寫
  ```
  curl -s "https://commons.wikimedia.org/w/api.php?action=query&titles=File:XXX.jpg&prop=imageinfo&iiprop=extmetadata|url&format=json"
  ```
  取 `extmetadata` 的 `LicenseShortName`／`Artist`；URL 用 `.../thumb/.../1280px-....jpg` 形式。
- **TCMB**：`python3 ~/MyWork/WaldorfTeacherOS-Repo/setup/scripts/tcmb-search.py --search "地名"`
  （不確定參數先 `--help`）。⚠️ **`tcmb.culture.tw` 線上站一律禁止 WebFetch／curl。**
  2026-07-28 實證：它掛站時部分請求「不回應也不逾時」，一支懸住的 WebFetch 就把整支
  agent 無聲凍死（當日三支＋前一晚兩支，共五支死於此，先前誤診為額度中斷）。
  TCMB 素材只走本機索引；線上拿不到授權欄位的圖直接不收。
- 每張 `curl -sI` 驗 200；拿不到授權資訊的圖**直接不收**，寧可少一張。
- **`images` 6–10 張，上限就是 10，不准超**（第一批有一篇 11 張）。
- 每張標 `section: 自然地理` 或 `section: 人文地理`——**只有這兩個值會被掛進章節**，
  寫別的（例如 `section: 定位速覽`）等於無效標籤，那張圖會掉到頁尾圖像廊。
- **避開已被其他頁用過的圖**：清單在
  每一批開工前用下面這段重新產生一份給 agent 讀（scratchpad 會被系統清掉，不要留在那裡當長期資產）：

  ```bash
  .venv/bin/python3 - <<'PY' > /tmp/used-images.txt
  import re, yaml
  from pathlib import Path
  used = {}
  for p in sorted(Path("content").rglob("*.md")):
      m = re.match(r"^---\s*\n(.*?)\n---\s*\n", p.read_text(encoding="utf-8"), re.S)
      if not m: continue
      try: fm = yaml.safe_load(m.group(1)) or {}
      except Exception: continue
      for img in (fm.get("images") or []):
          u = (img or {}).get("url")
          if u: used.setdefault(u, []).append(fm.get("name", p.stem))
  print(f"# 全站已使用的圖片 URL（{len(used)} 個），新頁請避開")
  for u, who in sorted(used.items()):
      print(f"{u}  ← {'、'.join(who)}")
  PY
  ```
- ⚠️ **YAML 值裡有冒號、`#`、引號時一律用雙引號包起來**。實測撞過
  `author: Minchi Chen（Flickr: minchi_chen）`——全形括號裡那個半形冒號讓整份 frontmatter
  解析失敗，下游腳本直接掛掉。
